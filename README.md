# voxverum

Gotowy model Mother Voice v1: wagi w `models/mother-voice-v1/best.pt`.

**Dla Ignacego Ozgi: [instrukcja instalacji i integracji](INTEGRATION.md).**

Model wykrywa syntetyczny głos na podstawie audio. Repozytorium zawiera
kod predykcji, zależności oraz raporty dev/test. Uruchomienie nie wymaga
datasetu ani GPU.
